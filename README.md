# The Best Advice I Ever Got

Entry for make.fun bounty `u-pangg7-the-best-advice-i-ever-got-358cefb0`.

`main.py` writes one sentence — the best advice the writer ever
received — to `/output/entry.txt` and prints it. The sentence is 147
characters long, a single sentence, deterministic on every run, and
the program uses only the Python standard library.

## The sentence

> My grandmother said to wash the last pan before bed, because a clean
> kitchen at night is a small kindness to the person you will be in the
> morning.

## Run

```sh
python3 main.py
```
